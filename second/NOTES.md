# Independent calculation judgments

Sources: only TASK.md, docs/dictionary.json, docs/spec.md, the two NCUA documents in docs/, and the supplied quarterly archives. No engine implementation was consulted.

- Scope: the dictionary has 11 measure IDs, producing 13 rows per credit union per quarter because both guarantee measures have two parts. Dictionary accounts with check/context roles are not additional measures. TASK.md defines this independent calculation's deliverables; the spec's website, publication workflow, and editorial flags are outside this script.
- Roster: use each quarter's FOICU STATE = NM and federally insured CU_TYPE 1 or 2; exclude type 3. Keep historical national account records so moving into NM does not discard a charter's earlier loan history. Charter number joins tables and quarters; no merger/predecessor substitution. Duplicate roster/table charters or duplicate account columns stop the calculation.
- Read comma-delimited quoted text using Windows-1252, normalizing header and member filename case. Locate accounts in actual FS220*.txt headers each quarter, without relying on table-name hints. A missing column, missing charter row, or blank account cell remains null; malformed/nonfinite numeric values fail. No retired account is substituted.
- Total loans use gross 025B, not loans net of allowances; 025B1 is a check account, not a fallback. Commercial share uses 400T1 divided by assets (010), not total loans.
- Net worth uses reported 998 / 100, as required by the dictionary. The instructions (printed p. 127, Schedule G section 4) allow elected asset denominators and CECL adjustments; simple net worth / quarter-end assets would not reproduce every filed ratio. No CECL subtraction is made. This resolves the spec's earlier general statement that the published ratio excludes CECL.
- Delinquency uses 041B / 025B, consistent with the FPR guide p. 7: 60 days or more, including leases.
- Charge-offs use the displayed algebra in the FPR guide p. 8. The prose has ambiguous subtraction grouping; subtracting the prior year's net amount means subtracting charge-offs and adding recoveries. Accounts 550 and 551 are year-to-date (instructions pp. 64–67). Compute current net + prior December net - same-quarter prior-year net, over the mean of current and prior-year loans. Negative net charge-offs are valid because recoveries can exceed charge-offs.
- In December the two prior-year net amounts cancel, so only current-year net charge-offs and both December loan balances are needed. Intermediate quarters are not needed by the FPR formula. Missing required endpoints yield null. TASK.md and the dictionary supersede the spec's older start-date wording: 2017-12 is read solely for charge-off history, permitting 2018-12; 2018-03 through 2018-09 remain null. No 2017-12 output is written.
- Commercial reset denominator is 718A3 + 718A4, exactly the accounts named for CM0099 in the instructions p. 90, rather than 718A5. Home/noncommercial reset is RL0050 / RL0047 (p. 79). Both require every operand; the retired combined 712 is not a substitute before the split.
- Guarantee balances include their guaranteed portion (instructions pp. 56–57); the two rows are not additive. These are reported account categories, not a USDA-only estimate. The instructions allow some balances with zero guarantees, including favorable junior-lien arrangements. Preserve both reported dollar amounts; the task's withholding rule applies to the four named percentage shares, not to raw guarantee balances.
- Zero/null denominators produce null. Test impossible shares against the unrounded result; write that unrounded Decimal result in withheld.csv, then omit the value from measures and peers. Do not cap values. Net worth and net charge-offs are not bounded shares and are retained even when negative or unusual.
- Decimal arithmetic avoids binary float ties. Percentages use ROUND_HALF_UP to two decimals; dollars/counts use whole-number ROUND_HALF_UP if fractional input occurs. Normalize rounded negative zero. CSV nulls are empty fields.
- Peers use the quarter's reported Peer_Group, restricted to groups 1–6, without estimating a group from assets. The selected charter is excluded even if its own measure is null; valid other values can still give it a peer comparison. Invalid/missing group yields n_others = 0. Counts exclude null and withheld values separately for each measure. For at least five others, sort already rounded values and interpolate at (n-1)*p for p = .25, .5, .75, then round halves up. Smaller groups have counts but empty statistics.
- Output order is quarter, numeric charter, then dictionary measure order; peer measure order is fixed. Published five-charter checks are assertions against independently computed values, never inputs to the calculations.
